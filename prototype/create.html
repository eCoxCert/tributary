Step 2 blocked

Tributary pays fees only to wallets listed in this file, so a launch cannot start without it. We found 4 commit authors on main and filled their weights from commit share. Each of them adds their own wallet.

  1. Add the file at the repository root

    Weights must add up to 1. Commit share is the usual starting point; you can change it before you merge.

    {
  "version": 1,
  "contributors": [
    { "github": "s-oduya",   "wallet": "", "weight": 0.52 },
    { "github": "m-feld",    "wallet": "", "weight": 0.27 },
    { "github": "cpaz",      "wallet": "", "weight": 0.14 },
    { "github": "r-ibsen",   "wallet": "", "weight": 0.07 }
  ]
}

  2. Ask each contributor to add their wallet

    One pull request per person is the cleanest record: the wallet then comes from the account that wrote the code. Leave out anyone who does not want a share and spread their weight over the rest.

  3. Merge to the default branch and check again

    Tributary reads the file at the latest commit on main and records that commit hash in the launch.
