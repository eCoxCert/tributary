How a launch moves along its curve

A launch is one bonding curve. Contributors get the first stretch of it, then it opens to everyone. When the curve fills, the token graduates to a liquidity pool.

  1. 1

    Commit .katki.json

    List contributor wallets and their commit share in one file at the repo root. Tributary reads it from the default branch at launch, so the split is public before anyone buys.

  2. 2

    Contributors buy first

    For the first 24 hours only wallets in the file can buy. The people who wrote the code get the lowest prices on the curve.

  3. 3

    Anyone trades, then it graduates

    After the window the curve is public. At 4.20 ETH raised, liquidity moves to a pool and trading continues there. Fees keep flowing to contributors.

Where the trading fee goes

1% of every buy and sell is set aside for the repository. It is split across the wallets in .katki.json by commit share, and each contributor claims their part when they want it.

  • Split by commit share. The weights come from the file you committed, so anyone can check them against the repo history.
  • Founder share stays locked. 5% of supply is locked for 180 days. The unlock date and the contract sit on every launch page.
  • No one holds the fees in between. They accrue in the launch contract until each contributor claims to their own wallet.
